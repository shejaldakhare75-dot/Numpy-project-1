# Employee Salary Analysis Using NumPy

A beginner-friendly Python project that analyses a sample set of employee salaries using NumPy.

## Features

- Stores salary values in a NumPy array.
- Calculates employee count, maximum, minimum, mean, and median.
- Calculates standard deviation and variance.
- Filters salaries above and below a selected threshold.
- Estimates salaries after five years of 5% annual compound growth.

## Technologies Used

- Python 3
- NumPy
- Jupyter Notebook

## Installation

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Move into the project folder:

   ```bash
   cd <repository-folder>
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Run the Project

Open `numpy_project.ipynb` using Jupyter Notebook or Visual Studio Code, then run all cells from top to bottom.

To launch Jupyter Notebook from the terminal:

```bash
jupyter notebook
```

## Sample Data

The notebook contains 15 sample salary values. They are illustrative values, not real employee records. The salary unit or currency is not specified.

## NumPy Concepts Demonstrated

`np.array()`, `.size`, `np.max()`, `np.min()`, `np.mean()`, `np.median()`, `np.std()`, `np.var()`, Boolean indexing, array arithmetic, and `np.round()`.
